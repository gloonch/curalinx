# Logos

The supplied Curalinx artwork, with transparent crops of it. Never redraw, recolour or separate these files.

- `curalinx-logo.png`: the primary lockup (navy #000064 wordmark, blue #296fe1 DNA mark) for white and light grounds.
- `curalinx-logo-reversed.png`: white wordmark with the blue mark, for `surface-inverse` (navy footer).
- `curalinx-logo-white.png`: all-white, for photos and gradients only.
- `curalinx-mark.png`: the DNA "X" alone, for favicons and app avatars only.
- `curalinx-logo-source.jpg`: the original file as supplied (white background).

The aspect ratio is 1089 : 209 (≈5.21 : 1). Keep clear space equal to the "l" height, with a minimum width of 96px.
